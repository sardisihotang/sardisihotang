### ❖ About Me

I'm an **Information Systems graduate from Universitas Gunadarma**, passionate about turning complex data into actionable insights and building practical web solutions. My primary interests are **data analytics, financial-market analysis, and data-driven problem solving**, supported by hands-on experience with **Python, Pandas, SQL, PHP, and Laravel**.

I enjoy connecting analytics with usable applications—from preparing and exploring datasets to designing reliable backends and intuitive interfaces.

▹ **Data Analytics:** Data cleaning, exploratory data analysis (EDA), and insight generation. <br>
▹ **Web Development:** Laravel/PHP applications, database design, and responsive interfaces. <br>
▹ **AI Integration:** Exploring LLM-powered workflows and automated insights. <br>
▹ **Currently Exploring:** Financial data patterns, technical indicators, and analytical systems.
